## What is Office App?

Office App is a mobile application that helps your business manage **worker attendance**, **timesheets**, and **site operations** from anywhere. Built for construction and field-based teams, it works even when you're offline.

## Quick Start by Role

### 🔧 For Foremen (Field Workers)

**Your daily workflow:**

1. **Open the app** → You'll see today's date and your assigned site
2. **Tap "Scan"** → Point camera at worker QR badges
3. **Workers check in** → Their attendance is automatically recorded
4. **At end of day** → Workers scan out
5. **Submit timesheet** → Send hours for supervisor approval

**Key screens you'll use:**

| Screen         | What you do there                |
| -------------- | -------------------------------- |
| **Home**       | See today's attendance summary   |
| **Scan**       | QR code scanner for check-in/out |
| **Workers**    | View your team members           |
| **Timesheets** | Submit and track timesheets      |
| **History**    | Review past days                 |

**💡 Tip:** The app works offline! Scans sync automatically when you're back online.

---

### 👷 For Supervisors

**Your daily workflow:**

1. **Check Home screen** → See pending approvals at a glance
2. **Review Approvals** → Timesheets waiting for your action
3. **Approve/Reject** → Process each timesheet
4. **Mark as Paid** → After payment is processed

**Key screens you'll use:**

| Screen        | What you do there             |
| ------------- | ----------------------------- |
| **Home**      | Dashboard with pending items  |
| **Approvals** | Review and approve timesheets |
| **Sites**     | Monitor site activity         |
| **Reports**   | View attendance reports       |

---

### 👔 For Administrators

**Your capabilities:**

1. **Dashboard Overview** → Company-wide metrics at a glance
2. **Manage Workers** → Add, edit, deactivate employees
3. **Manage Sites** → Configure work locations
4. **Review Timesheets** → Full visibility across all teams
5. **System Settings** → Configure app behavior

**Key screens you'll use:**

| Screen         | What you do there                     |
| -------------- | ------------------------------------- |
| **Home**       | Weekly attendance charts, key metrics |
| **Workers**    | Employee directory and management     |
| **Sites**      | Job site configuration                |
| **Timesheets** | Company-wide timesheet view           |
| **Settings**   | App configuration                     |

## Core Features Explained

### 📱 QR Code Scanning

Workers carry QR code badges. Foremen scan these to record:

- **Check-in time** (start of day)
- **Check-out time** (end of day)

The app plays a sound to confirm successful scans.

### 📋 Timesheet Workflow

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│              │    │              │    │              │    │              │
│   FOREMAN    │───▶│  SUBMITTED   │───▶│   APPROVED   │───▶│     PAID     │
│   Records    │    │  (Pending)   │    │ (Supervisor) │    │   (Final)    │
│              │    │              │    │              │    │              │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

### 📶 Offline Mode

**No internet? No problem!**

- Continue scanning workers as normal
- Add notes and photos
- View existing data

When you're back online, a sync icon shows pending items. They upload automatically.

### 🌙 Dark Mode

The app supports both light and dark themes for comfortable viewing in any lighting condition.

## Common Questions

### How do I log in?

Enter your company email and password on the login screen. Your role determines which screens you see.

### What if I scan the wrong worker?

You can delete individual scans from the attendance list. Tap on the scan and select delete.

### Can I use this without internet?

Yes! The app stores data locally and syncs when online. Look for the sync indicator to see pending items.

### How do I know a scan worked?

You'll hear a confirmation sound and see the worker added to today's list.

### Who can see my timesheets?

Your supervisor and administrators can view your submitted timesheets.
